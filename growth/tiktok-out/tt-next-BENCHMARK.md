### Winner B · 三法则清单动能（方榆 / ptetop 分步策略）
- 爆款结构不是长讲义，而是 **3 条可照做动作**：开口时限 → 抓主干 → 忘词不停。

- 本片 beats：① 3秒内开口 ② 抓主干（主谓宾数字）③ 忘词不停。

### Winner C · 流利优先金句（猩际评分权重叙事）

## Takeaways（发前必看）

1. Hook = 规则惩罚 + 数字，1.5s 内出「3 秒 / 录音」。
2. 三法则 = pattern interrupt 每 ~4s；忌一次甩完。
3. 不承诺提分/保分；不出现「无代考/无保分」刷屏（合规靠省略坏承诺）。
4. Caption：口语断行 + 1–2 emoji + 混搭 #PTE #RepeatSentence #新西兰华人 #跟读。
