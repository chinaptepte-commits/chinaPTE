# 发布时间 Insights · chinaPTE（TikTok + 小红书）

> 研究日期：2026-09-17（PT / Asia/Shanghai = AWST UTC+8）  
> 用途：定 cron 初值；**每周必须用自有数据 + 对标账号覆盖校验**（见文末）。  
> 主受众：TikTok = NZ 华人优先；小红书 = 国内 + 海外华人教育/干货。

## 时区换算（排期必看）

| 标签 | 相对 Asia/Shanghai（= 珀斯 AWST） |
|------|-----------------------------------|
| Asia/Shanghai / 珀斯 | UTC+8（基准；cron 一律写这个） |
| NZST（约 4 月–9 月末） | **+4h** → NZ 19:00 = 上海 15:00 |
| NZDT（约 9 月末–4 月） | **+5h** → NZ 19:00 = 上海 14:00 |
| AEST（悉尼冬） | +2h；AEDT（悉尼夏） | +3h |

NZ 夏令时切换约每年 9 月末；排「NZ 晚间」时：冬用 **15:00** 上海，夏可试 **14:00** 上海。

## TikTok（NZ/AU · 华人教育/打工英语）

### 公开规律（汇总）

| 市场 | 常见高峰（当地） | 来源类型 |
|------|------------------|----------|
| **新西兰** | 早 7–9；**晚 6–10**（短视频偏晚） | NZ 本地营销文（NinetyBlack 等）、NZ 社媒汇总 |
| **澳洲** | 早 7–9 AEST；午 12–2；**晚 7–10**；Tue/Thu/Fri 偏强 | HopperHQ / SocialPilot 等 2025–2026 指南 |
| **教育/教程类** | 更偏 **早通勤 + 午休**；娱乐偏晚 | AU 分内容类型表 |
| **中文教育/职场** | 用户「充电」窗口：通勤碎片、午休、下班后 | 与 XHS 学习赛道重叠的行为假设 |

**NZ 华人晚间优先换算（推荐锚点）**

| 目标 NZ 当地 | 上海/珀斯（NZST） | 上海/珀斯（NZDT） |
|--------------|-------------------|-------------------|
| 18:00–19:00 晚饭前后 | 14:00–15:00 | 13:00–14:00 |
| **19:00–20:00 晚高峰开端** | **15:00–16:00** | **14:00–15:00** |
| 21:00+ 过晚（工作日） | 17:00+ | 16:00+ |

AU 东岸晚高峰（7–10 AEST）≈ 上海 17:00–20:00（冬）/ 16:00–19:00（夏）；**珀斯本地晚高峰**就是上海同钟点 19:00–22:00。

### 推荐窗口（Asia/Shanghai）

| | 时间 | 覆盖逻辑 |
|--|------|----------|
| **主推 Primary** | **15:00** | NZST ≈ **19:00** 晚间开刷；NZDT ≈ **20:00**。贴合「NZ 华人晚间」主诉求，且仍落在 AU 东岸傍晚前。 |
| **备用 Backup** | **19:30** | 珀斯晚高峰 + 东岸晚间尾声；NZ 已偏晚（23:30 NZST / 00:30 NZDT），适合 AU/泛华人二次实验，不宜当 NZ 主档。 |

### 当前 cron：TikTok **11:30**

| 判定 | 说明 |
|------|------|
| **对 NZ 晚间：偏早/偏午后** | 11:30 上海 ≈ NZ **15:30**（NZST）/ **16:30**（NZDT）——午后，不是 18–22 晚高峰。 |
| **可保留作实验档** | 接近 AU 教育类「午间」与东岸下午；起号期有数据价值。 |
| **建议** | **现在改为 15:00**（主推）；11:30 可作 A/B 或周末备用，不必长期占主 cron。 |

## 小红书（教育 / 干货 · 国内 + 海外华人）

### 公开规律（汇总）

国内运营共识（创作者中心经验文 / 赛道表，2025–2026）：

| 窗口（CST = 上海） | 适合 | 备注 |
|--------------------|------|------|
| **07:30–09:00** | 职场/学习轻干货 | 通勤碎片；竞争相对小于晚高峰 |
| **12:00–13:30** | 知识卡片、清单 | 避开整点 12:00；可错峰 12:15 |
| **19:00–22:00** | **深度干货 / 教程**（流量最大） | 学习赛道亦强；大 V 扎堆时可 **19:00 卡位或 22:00+ 错峰** |
| 周末上午 10:00–11:30 | 攻略/长图文 | 工作日 10:00 不是最强教育档 |

海外华人：按**当地作息**对齐「早/午/晚」行为窗，而不是机械搬国内钟点；新加坡/港台等仍多按当地晚间。教育向另见周日晚「下周充电」窗口（约 19:00–21:00 当地）。

### 推荐窗口（Asia/Shanghai）

| | 时间 | 覆盖逻辑 |
|--|------|----------|
| **主推 Primary** | **19:30** | 国内教育干货晚高峰核心带；珀斯同步晚间；收藏/完读权重高的长图文更合适。 |
| **备用 Backup** | **12:15** | 午间摸鱼干货；竞争低于晚 20:00；海外华人午休亦可吃到。 |

（早档 **07:45** 可作第三实验：职场学习早高峰，适合短清单。）

### 当前 cron：XHS **10:00**

| 判定 | 说明 |
|------|------|
| **可用但不最优** | 偏周末指南/上午浏览；工作日教育干货弱于早通勤与晚黄金档。 |
| **对 NZ 晚间** | 10:00 上海 ≈ NZ 14:00/15:00——仍非晚间。 |
| **建议** | **现在改为 19:30**（主推干货）；若自动化只方便白天，可先改 **12:15**，再测晚档。 |

## Agent 强制动作（每周）

公开表只是起点。**每周至少一次**：

1. **自观**：TikTok Analytics → Followers / 活跃时段；小红书创作者中心 → 粉丝画像「活跃时间」。记录本账号 Top 2 小时。  
2. **对标**：抽 3–5 个竞品/对标账号（NZ 打工英语、PTE、澳新留学干货），记其近 7 条**实际发布时间**（当地或换算上海），看是否扎堆某小时。  
3. **决策**：若自有活跃峰连续 2 周偏离本文件主推窗 ≥ 90 分钟 → 改 cron，并在本文件「变更记录」追加一行。  
4. **发前**：见 posted-log 流程句——「发前自观数据 + 对标爆款发布时间」。
