# 小红书获客内容手册 · chinaPTE · 2026-10-01

> 设计原则：**纯获客有效性** = 搜索意图命中 → 停滑/完读/收藏 → 关注 → 点主页 → 点击 chinapte.net（UTM）→ 站内练习。  
> 不沿用旧「福清/厨房/日常包」教条做默认选题；以**搜索需求 + 平台红线 + 可测漏斗**重建。  
> 姊妹文档：`2026-10-01-nz-chinese-search-seo.md`。

## 1. 获客漏斗与红线

### 1.1 漏斗（要优化的行为）

```
搜索/推荐曝光 → 点击封面标题 → 完读/完播 → 收藏（资料包核心）
→ 关注 → 主页访问 → 软链点击（chinapte.net?utm…）→ 练习行为
```

### 1.2 硬红线（禁）

| 类别 | 禁用表达 / 行为 |
|------|-----------------|
| 效果承诺 | 保分、包过、保过、稳过、一次过、提分保证、速成必过 |
| 灰产 | 代考、泄题、真题贩卖、答案交易 |
| 引流 | 硬导个人微信/二维码/手机号为主 CTA；灰产站外交易 |
| 虚假 | 伪造上岸截图、虚构学员分数 |
| 刷量 | 买赞藏粉、互刷 |
| 版权 | 盗用他人题库音频/讲义大段搬运 |
| 妈祖 | 绑考试/学业/PTE；反讽「拜了就能过」亦禁 |
| 类比违规 | 医疗疗效式、金融保本式类比到提分 |

依据方向：广告法风格效果承诺限制 + 平台教育类治理（过审指南/社区公约类公开讨论）。[A][B][C]

### 1.3 软 OK（主推）

- 免费练习工具、真实技巧拆解、行业词表资料包  
- 诚实边界：「适合练手感 / 不替代官方评分 / 不提供移民建议」  
- CTA：`https://chinapte.net/<path>?utm_source=xiaohongshu&utm_medium=social&utm_campaign=<slug>`  
- 先收藏 → 再软关注 → 主页链站点

## 2. 2025–2026 教育/工具类公开实践摘要（用于设计，非抄旧账号）

公开运营文与平台教育向讨论中反复出现的可复用点（**不引用未验证的账号私有数据**）：

1. **搜索拦截**：标题前约 14 字放核心搜索词；中腰部长尾优于超大泛词硬刚。[D]  
2. **知识驱动**：干货密度 > 硬广；图文字数常见建议约 400–800（资料包 caption 可更短，价值在多图）。[D]  
3. **收藏率**是教育类关键存留指标（行业文常提收藏门槛意识）；资料包形态服务收藏。[D]  
4. **结构**：痛点/数字/反差钩 → 可执行步骤 → 诚实边界 → 软资源 CTA。[E]  
5. **视频**：教育向需要足够信息量；职业对话短视频仍可用 15–35s，但钩子 3s 内必须给冲突。[D]  
6. **合规经营**：真实分享、反对虚假与对立；留学/教培过度营销曾被治理。[C]

## 3. 双形态策略

### 3.1（A）短视频

| 项 | 规范 |
|----|------|
| 时长 | 职业对话 15–35s；技巧讲解可至 ~60s（需强前 3s） |
| 结构 | **0–3s Hook** → 价值 beats（3 句/3 锚点）→ **软 CTA**（站点/练习） |
| 画面 | 真人感 B-roll 或清晰口播卡；禁空镜幻灯片充数 |
| 字幕 | 大字关键词；封面字 ≤12 |
| 文案 | 平台原生，勿直接粘贴 TikTok caption |
| 双发 | TT 已发 occupational → 同日/当晚 XHS 同成片（见 `crosspost-video.md`） |
| 午/晚 | **晚槽优先视频**（完播与双发窗口）；午槽除非纯技巧口播 |

**脚本模板**

```
[HOOK · 0–3s]
「{场景}第一天听懵了？先别慌——」
或「WFD 听完一片空白？你可能漏了这个锚点」

[VALUE · 3–25s]
要点1（词/方法）→ 要点2 → 要点3
每点：英文原词 + 半句中文场景

[SOFT CTA · 最后 3–5s]
「完整词表/跟读练习在 chinapte.net 练习中心（主页也有）」
口播可只说域名；caption 放完整 UTM
```

### 3.2（B）图文 / 多图资料包

| 项 | 规范 |
|----|------|
| 默认 | 题型速查、行业词表 → **资料包 ≥6 页**（封面+分类卡+末页） |
| 小短文 | 仅故事/心态/入口说明；词表类禁止薄 tip |
| 封面 | ≤15 字；搜索词 + 数字利益 |
| caption | 150–400 字说明用法；不把整表塞进正文 |
| CTA | 先收藏 → 软关注 → UTM 一次 |
| 视觉 | 3:4；统一模板；像「能翻的笔记」 |

**资料包页结构**

1. 封面：核心搜索词 +「资料包」  
2–N. 每页一类：6–12 条（EN + 中文 + 半句场景）  
末页：怎么用 + 软链练习中心 +「不保分、只练手感」

## 4. 选题评分量表（获客）

每题 1–5 分，**总分 ≥14** 才进 14 日日历；任一红线项直接 0 分否决。

| 维度 | 1 | 3 | 5 |
|------|---|---|---|
| 搜索意图代理 | 无人对着搜 | 长尾痛点词 | 标题可直接当搜索词 |
| 痛点强度 | 弱好奇 | 明确卡点 | 「第一天听不懂/写不出」级 |
| 软 CTA 契合 | 难接站点 | 能接行业/技巧页 | 自然接 practice/wfd/rs/industry |
| 合规风险 | 擦边承诺 | 需小心措辞 | 纯工具/词表/事实 |
| 差异化 | 近 7 日已发同钩 | 同桶新角 | 新桶或新拆角 |
| 收藏潜力 | 一眼即走 | 可截图 | 多页可反复翻 |

**否决词**：保分/包过/代考/妈祖×考试/纯厨房复读/无搜索词的日常流水账。

## 5. 封面 / 钩子公式

**封面**

- `{搜索核心词}` + `{数字}` + `{资料包|速查|跟读}`  
- 例：`WFD听写｜3个锚点速查` · `护理英语｜8类词表`

**标题钩子（选一）**

1. 痛点提问：`WFD听完不会写？先抓这3个锚点`  
2. 场景冲突：`工地第一天对讲机听懵了怎么办`  
3. 反差：`以为要背全文，其实只要…`  
4. 清单利益：`新西兰打工英语｜6类开箱词`  
5. 事实澄清：`新西兰技术移民英语考什么（只讲公开要求）` — **禁止**解读成「我帮你办签」

## 8. 测量

### 8.1 创作者侧（趋势，不编 KPI 绝对值）

- 曝光→点击（封面/标题）  
- 完播率 / 完读翻页  
- **收藏**、关注、评论问法（是否在要「链接/题库」）  
- 主页访问  

### 8.2 站点 UTM

| 参数 | 约定 |
|------|------|
| utm_source | `xiaohongshu` |
| utm_medium | `social` |
| utm_campaign | 与 slug 一致 |
| 可选 utm_content | `noon` / `evening` |

看：campaign 落地页 PV、练习中心进入、WFD/RS 播放（有则记）。
