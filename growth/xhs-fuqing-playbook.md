## 0. 调研摘要（小红书 & 同乡语境怎么出现）

### 平台上「福清人」常见出现方式
| 信号 | 观察 | 对本账号含义 |
|------|------|--------------|
| 同乡网络叙事 | 论坛/同乡会语境强：亲戚带路、油漆/装修/工地学徒、墨尔本·悉尼福清同乡会 | 钩子用「老乡/同乡场景」比空泛「华人出海」更准 |
| 澳新打工内容 | 小红书上更多是「新西兰生活对账」「澳洲工地/施工」「打工英语」泛标签；「福清」常作身份锚点出现在正文/评论，不一定单独成热搜话题 | **地理标签（#澳洲打工 #新西兰打工）+ 身份词（#福清 #福清人）混搭** |
| 痛点 | 听不懂工长/induction；英语差仍靠亲友入行；签证/语言分卡关；黑中介高薪话术（近年诈骗报道多） | 我们只做**英语够用 + 免费练习 + 合规路径说明**，不碰签证承诺 |
| 文化态度 | 「骄傲的福清人」「出海闯一闯」是同乡自述常见语气 | 尊重勤劳与互助；**禁止**「福清人只会打工/只会搞钱」等刻板话术 |

### 已验证 / 建议试用的搜索与话题词
**高相关（优先试）**
- `#福清` `#福清人` `#福建人` `#福清同乡`
- `#澳洲打工` `#新西兰打工` `#澳新打工` `#华人出海`
- `#工地英语` `#行业英语` `#建筑英语` `#橱柜`
- `#PTE` `#PTE备考`（与签证语言分场景弱绑定，不承诺分数）

**可测（观察搜索量/推荐，2 周后留优去劣）**
- `#福清出海` `#福清在澳洲` `#福清在新西兰` `#港头`（镇级过窄，慎用）
- `#油漆工` `#装修英语` `#site induction`

**避免**
- 恐吓式「不去就穷了」、夸大月入、暗示黑工/绕签、代考保分词
- 地域歧视梗、方言羞辱、性别刻板

## 1. ICP（理想客户画像）

### 主 ICP：准备/已在澳新工地的福清同乡
- **是谁**：18–40 岁，福清及周边（含港头等侨乡网络），本人或亲友在 AU/NZ 油漆、橱柜、建筑、工厂
- **场景**：出发前恶补英语；刚到听不懂 toolbox talk；想考 PTE 凑语言分/学习路径但仍在打工
- **动机**：听懂指令 = 少挨骂少出事；英语够用 → 更好班组/涨薪谈判空间；合规了解出国路径（非包办）
- **内容偏好**：短词表、场景句、可收藏清单；同乡口吻；免费可点开就练
- **转化路径**：笔记收藏 → 主页 → chinapte.net 行业英语/WFD → （可选）labor/consult 合规说明留资

### 次 ICP：家人帮亲戚「做功课」的福清家属
- 在国内搜「福清 澳洲 英语/打工」；帮弟弟/表亲找免费资源
- 钩子：给家里人收藏的「出发前必会 10 词」

### 非 ICP（不追）
- 纯留学雅思冲分卷王、纯旅游晒图、要代考/包过的人

## 2. 楔子（Chosen Wedge）

**「福清老乡 · 澳新工地够用英语」**  
用同乡身份锚点 + 工地/橱柜真实场景词，把 chinaPTE 的行业英语与 PTE 碎片练习绑成「出海前/工地旁就能用的免费工具」。

为何是楔子（非宽泛华人）：
1. 福清侨乡 → 澳新蓝领路径密度高，内容共鸣强  
2. 账号已有橱柜/建筑行业英语资产，可立刻产品化  
3. 同乡评论（「港头的」「表亲也在墨尔本」）可自验证流量是否打穿目标人群

## 3. 管用钩子（Hooks that work）

| 类型 | 示例标题方向 | 备注 |
|------|--------------|------|
| 同乡点名 | 「福清老乡去澳新，工长这几句先听懂」 | 身份 + 场景 |
| 反常识够用 | 「英语不好也能先干活——但这 8 个词别不会」 | 尊重现实，不贩卖焦虑 |
| 清单收藏 | 「橱柜班组高频词｜同乡收藏版」 | 拉高 saves |
| PTE 关联 | 「为啥工地老乡也在刷 PTE？」 | 软解释语言分/长期规划，不保分 |
| 家属向 | 「家里人要去澳洲工地，先把这页发给他」 | 次 ICP |

**封面公式**：大字少字 + 身份词（福清/老乡）+ 数字（5词/8句）+ 场景（橱柜/安全帽剪影）；禁止 PPT 墙。

## 4. Topic Buckets（选题桶）

1. **福清老乡澳新工地英语** — PPE、measure、flush、hinge、hazard、induction  
2. **PTE 为啥跟出海有关** — 语言分场景说明 + 免费 WFD/RS；明确不保分  
3. **同乡高频场景词** — 橱柜 / 油漆 / 安全 / 日常买菜租房短句  
4. **出发前 7 天英语清单** — 家属可转  
5. **合规提醒轻帖**（低频）— 「高薪包办」话术怎么识别信息差；只指向 `/labor.html` 说明页  

轮换：同乡工地词 → PTE 关联 → 场景词清单；连续两篇不得同桶。

## 6. A/B Test Plan（标题变体）

### Experiment FQ-1 · 同乡身份 vs 泛华人（同一正文骨架）
| 变体 | 标题 |
|------|------|
| A | 福清老乡澳新工地｜先会这 5 个英语词 |
| B | 澳新工地英语｜华人出海先会这 5 个词 |

**判据（48h）**：Saves/Views、Profile/Views、评论中出现福清/同乡/镇名/亲属出海的占比。  
**预期**：A 曝光可能略低但 **同乡意向密度更高**（收藏+主页）；若 A 全面劣于 B → 身份词改放正文首行而非标题。

### Experiment FQ-2 · PTE 关联强度
| 变体 | 标题 |
|------|------|
| A | 工地老乡也在刷 PTE？先搞懂它跟出海的关系 |
| B | 碎片 10 分钟｜WFD 三步法（打工党也能练） |

**判据**：PTE 帖的站内 `utm_campaign` 落地 vs 纯工地词帖；是否引来「要代考」类评论（有则立刻弱化考试承诺语气）。

### 执行节奏
- FQ-1：嵌在下一篇橱柜帖（见 posted-log）；48h 后记分  
- FQ-2：橱柜后 1–2 篇发 PTE-同乡关联稿（content-bank「福清同乡」#2）  
- 同一 slug 只换标题/封面做 A/B，**不改 slug**

## 7. Success Metrics（怎样算打穿福清楔子）

| 指标 | 起步健康线 | 楔子特有信号 |
|------|------------|--------------|
| Saves/Views | ≥ 2% | ≥ 3% → double-down 同结构 |
| Profile/Views | ≥ 1% | — |
| 福清编码评论/搜索痕迹 | — | 评论含：福清/融/港头/同乡/表亲在澳新；或创作者中心搜索词含福清相关 |
| 站内 UTM | 同 campaign 有 page_view | `xhs-fq-*` 系列落地 |
| 关注质量 | 涨粉即可 | 简介访问后停留/回访（定性看主页） |

**综合分**沿用主 playbook：`views + 3*saves + 2*comments + 4*profile_clicks`，另加一列「同乡信号数」。

## 8. Kill Criteria（停或改）

在 **48h**（曝光 <200 则延长到 7 天）后：

| 条件 | 动作 |
|------|------|
| Saves/Views < 1% 且 Score 低于账号中位 | Kill 该标题结构；换桶或把「福清」移入正文 |
| 48h 内 0 条同乡编码互动，连续 3 篇同乡向 | 暂停标题点名福清；改为「福建侨乡/澳新工地」泛化 2 周再测 |
| 评论集中要微信/代考/包过 | 统一回复站点链接；该角度停；检查是否标题过承诺 |
| 歧视/对立向引战 | 下架或关评；话术回调敬意模板 |
| 平台违规提示 | 立即下架同类 |
