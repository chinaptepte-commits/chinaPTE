Worker 部署步骤（一次性）

  1. 打开仓库 workers/analytics/，按其中 README 用 wrangler 创建 KV 并 npx wrangler deploy。
  2. Cloudflare 为 chinapte.net 添加路由 /api/analytics* → 该 Worker。
  3. npx wrangler secret put ADMIN_KEY，并把同一值填进上方或 admin/config.js 的 CHINAPTE_ANALYTICS.adminKey。
  4. 可选：设置 ga4MeasurementId 或 CHINAPTE_ANALYTICS_WEBHOOK 作为双写。

修改密码：编辑仓库里的 admin/config.js，改 window.ADMIN_PASSWORD 后推送到 main。
