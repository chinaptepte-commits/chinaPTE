登录

默认密码见 admin/config.js 中的 ADMIN_PASSWORD（初次为 chinaPTE2026）。 请登录后尽快改成你自己的密码并重新部署。

编辑出国劳务页（labor.json）

列表字段请一行一条。保存会通过 GitHub API 更新仓库 chinaptepte-commits/chinaPTE 的 content/labor.json。

到 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) 新建，勾选 repo。Token 不会上传到本站服务器（本站无后端），只存在你本机 sessionStorage / localStorage。

修改密码：编辑仓库里的 admin/config.js，改 window.ADMIN_PASSWORD 后推送到 main。
